# Surface Brief — Landing Page (Beranda)

**Scope:** Primary marketing surface, route `/` (src/pages/index.astro).
**Visitor mode:** Persuade.

**Audience:** Trade/project buyers (contractors, procurement, architects) and individual/renovator buyers — both mobile-first, WhatsApp-driven, Indonesian.

**Job:** Understand in seconds that BSM is a one-stop factory-price distributor, see BRC fencing built to spec, and request a quote.

**Action:** Tap the blueprint-stamped WhatsApp CTA (primary) or "Lihat Katalog" (secondary). No cart, no checkout.

**Proof / content:** Real BRC specimen photography (dimensioned), delivery-network diagram (34 provinsi), trust strip (nationwide · 6 groups · ready stock · free Surabaya/konsultasi), 6-category grid, featured BRC products, blog teaser, contact close.

**Constraints:** Indonesian only; no public prices (quote on request); Decap-managed blog (posts are placeholder until CMS wired); single static site; safety-orange is CTA-fill only; blueprint-indigo at region scale.

**Chosen direction:** Blueprint Field (new-work, concept-seed assigned index 6/7, key bsm-bangun-saranamakmur). Drafting-paper ground, mesh grid = layout grid, dimensioned specimen as signature component.

**Memorable moment:** The hero BRC panel drawn as a dimensioned engineering sheet with callouts that draw in on load.

**Unresolved decisions:** Deployment host + Decap git backend/OAuth; whether a formal a11y standard (WCAG 2.1 AA) is required; catalog inner pages and blog post templates not yet built (linked as stubs).
